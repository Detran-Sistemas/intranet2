Este documento serve como referência visual e técnica para todos os elementos Markdown suportados nativamente pelo editor da Intranet do Detran-MG (Wiki.js). Use esta página para validar o SCSS do novo Design System.

2. Tipografia e Formatação de Texto

O texto fluido principal é definido em slate-600 com espaçamento de linha relaxado para leitura em telas grandes. Aqui estão as variações:

  • Negrito: Use para destacar palavras-chave importantes.
  • Itálico: Use para estrangeirismos ou ênfase leve.
  • Tachado: Informação obsoleta ou revogada.
  • Código Inline: Use para referenciar comandos como npm install ou variáveis do sistema.
  • Links Externos ou Internos recebem a cor primária e sublinhado no hover.

3. Listas Estruturadas

Lista Não Ordenada (Ul)

  • Primeiro item da lista com marcador customizado.
  • Segundo item, contendo uma sub-lista para testar aninhamento:
    • Sub-item A (nível 2)
    • Sub-item B (nível 2)
  • Terceiro item da lista raiz.

Lista Ordenada (Ol)

  1. Passo inicial do procedimento.
  2. Processamento no sistema local.
  3. Validação final com a base estadual.

Lista de Tarefas (Task List)

  • Atualizar layout do header.
  • Injetar tipografia Tailwind.
  • Homologar componentes no ambiente de staging.

7. Imagens Responsivas

As imagens enviadas para a intranet são automaticamente arredondadas, ganham uma borda sutil e preenchem a largura do contêiner.

8. Blocos Especiais (Wiki.js Native Extensions)

Os blocos abaixo são renderizados pelo Wiki.js inserindo as diretivas > [!info], > [!warning], etc. O CSS intercepta essas classes.

Bloco Info: Usado para informações neutras, dicas de uso do sistema ou notas explicativas adicionais.
Bloco Success: Ideal para mensagens de sucesso, como "O sistema está operando normalmente" ou "Operação validada". (Usa o verde institucional).
Bloco Warning: Alertas importantes que exigem atenção, como prazos de sistemas próximos do vencimento ou instabilidade parcial.
Bloco Danger: Informação crítica. Sistemas fora do ar, quebra de regras de segurança ou procedimentos bloqueados.

Lista de Links Visuais (.links-list)

Esta é uma funcionalidade nativa útil do Wiki.js para criar matrizes de botões (grid) a partir de listas não ordenadas, apenas adicionando {.links-list} ao final do Markdown. Suporta descrições inserindo *descrição* entre asteriscos:

  • Manual do Sistema de Veículos Procedimentos operacionais para gestão de frota e emplacamento
  • Portal de Atendimento (UAI) Agendamentos presenciais e consultas de serviços ao condutor
  • Tabela de Taxas Vigentes 2026 Valores atualizados de DAE para licenciamento, CNH e vistorias
  • Base de Conhecimento TI Tutoriais técnicos, abertura de chamados e acessos internos
